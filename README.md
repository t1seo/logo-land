# Logo Generator

로고 생성 플러그인을 개발하기 위한 프로젝트입니다.

## 현재 상태

플러그인 설정 파일과 개발 폴더를 준비했습니다. 로고 생성 기능과 외부 서비스 연동은 아직 구현하지 않았습니다.

## 구조

- `.codex-plugin/plugin.json`: 플러그인 이름과 표시 정보
- `skills/`: 로고 생성 워크플로 스킬을 추가할 위치

## 저장소

- GitHub: https://github.com/t1seo/logo-generator
- 기본 브랜치: `main`

Orca에서 이 폴더를 열어 개발을 이어가시면 됩니다.
