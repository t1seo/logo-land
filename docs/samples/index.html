    02 / FROM WORDS TO FORMS

    말로 시작해,
    형태로 다듬습니다.

    브랜드 이름과 원하는 분위기만으로
    첫 시안의 방향을 정할 수 있습니다.

    1. 01

      원하는 로고를 말해주세요.

      브랜드 이름, 업종, 로고에 들어갈 글자와 색상을 알려주세요. 샘플 상세의 실제 요청을 참고하셔도 좋습니다.

      REQUEST / 요청
    2. 02

      요청이 첫 시안이 됩니다.

      요청을 바탕으로 생성 프롬프트를 만들고 이미지를 생성합니다. 각 샘플에서 사용한 프롬프트와 결과를 함께 확인하세요.

      GENERATE / 생성
    3. 03

      확인하고, 더 가깝게 다듬어요.

      글자와 형태를 살피고 바꾸고 싶은 부분을 구체적으로 요청하세요. 결과를 선택해 내보내면 PNG와 패키지를 받을 수 있습니다.

      REFINE / 수정·내보내기
