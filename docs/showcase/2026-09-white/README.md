## Refinements

Four selected samples include targeted native edits: LUMA restores an uppercase M, BREAD & BLOOM replaces bean-like details with wheat, Daybreak uses a round sun, and 틈 restores a missing consonant stroke. The [manifest](manifest.json) links each selected prompt and its initial original. [Visual review](visual-review.json) records size-specific observations and remaining limitations; [background samples](background-checks.json) report the native near-white pixel variation without claiming exact HEX conformance.
