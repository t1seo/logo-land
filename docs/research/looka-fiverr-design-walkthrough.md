# Looka · Fiverr · Design.com 직접 사용 기록

조사일: 2026-09-12. 가상 브랜드 `Morrow Studio`를 동일하게 입력했습니다. 아래는 Orca 내장 브라우저에서 직접 관찰한 화면입니다. 이후 사용자의 요청으로 외부 Chrome + Codex Computer Use로 전환했습니다. Chrome 추가 확인은 별도 항목에 기록합니다. 공식 설명과 실제로 실행한 기능을 구분합니다.

## Looka

1. [브랜드 입력](screenshots/looka-01-entry.png) → [업종](screenshots/looka-02-industry.png): Design Agency.
2. [선호 로고](screenshots/looka-03-preferences.png) → [색상](screenshots/looka-04-colors.png) → [이름·슬로건](screenshots/looka-05-name.png).
3. [심볼 카테고리](screenshots/looka-06-symbols.png), [직접 심볼 찾기](screenshots/looka-07-custom-symbols.png): 검색 및 최대 다섯 개 선택 흐름. 취향 질문은 건너뛸 수 있습니다.
4. [생성된 목록](screenshots/looka-09-results-loaded.png): 여러 조합, 로고 선택·즐겨찾기·Customize.
5. [편집기](screenshots/looka-12-editor-loaded.png): Suggested, Layout, Palette, More Ideas, Background, Name, Slogan, Symbol, Container, History, Your Logos. Make a Copy, Undo, Share, Download도 표시됩니다.
6. [이름 편집](screenshots/looka-13-name-controls.png): 문구, Stack, 크기, 대소문자, 글꼴 분류·색상·최근 목록. [레이아웃 대안](screenshots/looka-15-layout.png)은 완성된 배치별로 비교합니다.
7. 같은 편집기 아래에 명함·소셜 프로필/커버·이메일 서명·레터헤드·브랜드 가이드·광고·포스터 등 Brand Kit 사용 예가 표시됩니다. 구독 포함 안내이며 실제 다운로드까지 검증한 것은 아닙니다.

Customize를 눌러 생긴 일부 새 탭은 `/editor/loading`에 머물렀습니다. 화면에 표시된 Saved Logos의 Edit 링크를 확인해 실제 편집기 URL로 이동했습니다. `looka-08`, `10`, `11`, `14`는 로딩·전환 중간 증거이며 해당 파일명만으로 편집 완료를 의미하지 않습니다.

## Fiverr Logo Maker

1. 첫 진입은 사람 확인으로 막혔으며 사용자가 직접 해제했습니다. [해제 후 화면](screenshots/fiverr-02-entry-unblocked.png).
2. [Step 1](screenshots/fiverr-03-brand.png): 브랜드명과 선택 슬로건.
3. [Step 2](screenshots/fiverr-04-industry.png): 업종 최대 세 개, 원하는 요소 키워드(Enter로 구분). Design Agency를 선택했습니다.
4. [Step 3](screenshots/fiverr-05-style.png): Minimalist, Hand-Drawn, 3D, Geometric, Vintage, Cartoon을 복수 선택할 수 있습니다. Minimalist와 Geometric으로 진행했습니다.
5. [Step 4](screenshots/fiverr-06-personality.png): Accessible–Premium, Classic–Modern, Traditional–Innovative, Fun–Serious, Simple–Sophisticated의 다섯 단계 슬라이더. Modern 쪽으로 조정하고 Make My Logo를 실행했습니다.
6. [결과](screenshots/fiverr-07-results.png): 디자이너별 로고와 변형 개수, 워터마크, 브랜드명·슬로건 재입력, 더 보기. 순수 텍스트-이미지 생성 UI와 달리 디자이너 디자인 매칭이 드러납니다.
7. [편집 진입의 가입 화면](screenshots/fiverr-08-edit-signup.png): Google/Apple/Facebook/이메일. Google 진행을 시도했습니다. 인증 후 편집과 결제 후 파일은 아직 직접 검증한 것으로 표시하지 않습니다.

처음 CAPTCHA 화면은 원시 관찰 자료에 남아 있지만 대표 갤러리에서는 제외합니다. 자동으로 사람 확인을 우회하지 않았습니다.

## Design.com

1. 제공된 maker 주소(할인 코드 포함)에서 [브랜드 입력](screenshots/design-01-entry.png).
2. [결과 목록](screenshots/design-02-results.png): 키워드, 색, Abstract/Mascot/Emblem/Corporate/Wordmark/Vintage/Classic 필터, 일부 FREE 표기, 레이아웃 변형.
3. [실제 편집기](screenshots/design-04-editor-loaded.png): Preview, Share, Save Progress, Download, Undo/Redo, 레이어·뒤집기·불투명도·확대.
4. [Text](screenshots/design-05-text.png): 문구, 글꼴, 크기, 정렬, 자간, 굽은 글자, 윤곽선, 그림자, 텍스트 추가, AI Edit.
5. [Layout](screenshots/design-06-layout.png): 약 15개 아이콘·텍스트 배치. [Background](screenshots/design-07-background.png): 추천/사용 색, 기본 팔레트, 사용자 색, 그라데이션.
6. [Logo](screenshots/design-08-logo.png): 심볼 구성색과 AI Edit. [Shapes](screenshots/design-09-shapes.png): 카테고리·검색·추가 도형.
7. [Animate](screenshots/design-10-animate.png): 페이지/요소 단위. Rise, Slide, Bounce, Shake, Pop, Fade, Scale, Pulse, Flicker, Wipe, Spin, Tumble, Stamp, Random, Blur 등이 표시됩니다. 메뉴 관찰이며 애니메이션 파일 다운로드 완료를 의미하지 않습니다.
8. [AI 패널](screenshots/design-11-ai.png): 자연어 입력과 음성 입력 버튼. ‘기하학 M으로 단순화하고 forest green으로 변경’을 실제 제출했습니다. [응답 화면](screenshots/design-12-ai-request.png)에서 변경 결과와 겹친 글자를 추가로 수정할 수 있다는 설명이 나왔습니다. 음성 입력은 실행하지 않았습니다.
9. Download에서 이메일 또는 Google/Facebook 가입을 요구했습니다. Google 진행 시 Orca 프로필에 로그인 세션이 없어 이메일 폼이 표시됐습니다. 이후 사용자가 기존 로그인 세션이 있는 Chrome 사용을 지정했습니다.

`design-03-editor`는 이동 전 목록이며 대표 편집 증거는 `design-04-editor-loaded`입니다. 모든 유료 출력 형식은 [공식 기능 조사](official-features.md)의 확인 수준을 함께 참고하세요.

## 플러그인에 반영한 판단

브랜드 정보의 점진적 수집, 유형과 스타일의 구분, 서로 다른 시안 비교, 선택안의 자연어 수정, 원본 보존, 응용 크기 확인을 반영했습니다. 웹사이트의 고정 템플릿·결제·회사 설립 절차는 로고 생성 플러그인의 필수 과정에 포함하지 않았습니다. PNG 중심의 실제 내장 이미지 출력 범위와 경쟁사의 벡터 편집 범위를 구분합니다.
