# 로고 제작 서비스 공식 기능 조사

조사일: **2026-09-12 (Asia/Seoul)**  
대상: Looka, Brandmark, Tailor Brands, Fiverr Logo Maker, Design.com  
담당 산출물: `docs/research/official-features.md`, `docs/research/sources.json`

## 조사 범위와 확인 수준

공식 제품 페이지, 요금 안내, 도움말, 제작 튜토리얼, 공개 도구 설명을 웹 검색으로 찾고 실제 URL을 열어 읽었습니다. 출처 목록에는 본문을 읽은 페이지와 본문 추출 또는 열기에 실패한 페이지를 구분했습니다. 웹 도구가 제공한 문서는 캐시를 포함할 수 있으므로 **접근일은 원문 갱신일을 뜻하지 않습니다**.

이 보고서는 **공식 문서의 주장에 대한 확인**입니다. 브라우저 탭을 열거나 계정을 만들지 않았으며, 로고 생성·편집·결제·다운로드·한글 입력을 직접 실행하지 않았습니다. 따라서 “공식·높음”도 실제 동작을 재현했다는 뜻은 아닙니다. 공개 문서에서 식별한 기능상 제작 경로를 최대한 수집했지만, 계정별 실험 화면이나 비공개 기능까지 빠짐없이 확인했다고 주장하지 않습니다. 업종별 SEO 페이지는 독립 생성 엔진으로 중복 집계하지 않았습니다.

| 표기 | 의미 |
| --- | --- |
| **공식·높음** | 공식 도움말·가격표 본문에 기능이나 조건이 명시되어 있습니다. |
| **공식·중간** | 공식 마케팅 설명, 오래된 도움말의 현재성, 패키지 범위가 불명확한 주장입니다. |
| **역사적 공식** | 공식 기술 설명이지만 작성자가 이후 앱 변경을 명시했습니다. 현재 구현으로 단정하지 않습니다. |
| **색인·낮음** | 공식 URL의 검색 색인에서만 내용을 확인했으며 직접 본문 열기는 실패했습니다. |
| **추론** | 여러 문서의 연결 관계로 해석한 내용입니다. 문서의 직접 주장과 구분했습니다. |
| **미검증** | 공개 근거가 없거나 실제 사용으로 확인해야 합니다. “지원하지 않음”과 다릅니다. |

숫자와 가격은 확인된 문서의 표기이며 최종 결제 견적이 아닙니다. 권리 관련 내용도 각 서비스의 공개 설명을 요약한 것이며 개별 로고의 독점성이나 상표 등록 가능성을 검증한 결과가 아닙니다.

## 2. Looka

### 2.1 생성 경로·입력·메커니즘

| 경로 | 입력과 진행 방식 | 확인 수준 |
| --- | --- | --- |
| Logo Maker / AI Logo Generator | 회사명과 선호 로고 스타일·색상·심벌을 선택하고 후보를 생성합니다. 후보를 스크롤하면 추가 디자인이 나오며 즐겨찾기 → 편집 → 목업 확인 → 구매로 이어집니다. | 공식·높음. [제작 흐름][L01], [AI 생성 안내][L02] |
| 저장한 로고에서 계속 제작 | 로고를 열어 수정하거나 하트로 저장합니다. 가입 계정에서는 변경 사항을 자동 저장하며 로고를 계속 보관한다고 안내합니다. | 공식·높음. [저장][L03] |
| 기존 디자인 복제 | 편집기의 Make a copy로 원본을 보존하고 다른 버전을 만듭니다. 신규 생성 엔진이 아니라 분기 편집 경로입니다. | 공식·높음. [복제][L18] |

| 고객지원의 특수문자 추가 | 일부 특수문자를 지원팀이 별도 프로그램으로 추가한 파일을 제공합니다. 계정 로고나 Brand Kit에 반영되지 않으며, 최종 디자인에 1회 적용하는 별도 후처리입니다. | 공식·높음. [특수문자][L24] |

**메커니즘:** 디자인 선호도와 디자인 원칙을 AI가 조합해 후보를 만든다는 공식 설명입니다. 심벌 도움말은 자체 심벌 데이터베이스를 사용한다고 명시합니다. 이를 근거로 텍스트·폰트·심벌·컨테이너를 조합하는 구조를 확인할 수 있지만, 모델 이름, 학습 데이터 전체, 확산 모델 사용 여부, 완전히 새로운 심벌 생성 여부는 공개 근거가 없습니다. Logo Maker와 AI Logo Generator가 별도 엔진이라는 근거도 찾지 못했습니다. [AI 생성][L02], [심벌 데이터베이스][L19]

**로고 유형:** 텍스트 중심, 심벌 결합, 모노그램, 컨테이너로 둘러싼 형태를 문서상 확인했습니다. 컨테이너 분류에는 Filled, Outline, Abstract, Brush, Funky, Grunge, Elegant, Modern, Ornate가 있습니다. 이 목록은 편집기 컨테이너 분류이며 독립적인 생성 모델 종류가 아닙니다. 마스코트·엠블럼 등 일반적인 디자인 분류를 모두 독립 온보딩 선택지로 제공한다고는 확인하지 못했습니다. [심벌 추가][L12], [모노그램·간격][L16], [컨테이너][L17]

**외부 자산 제한:** 로고 편집기에 자체 심벌이나 폰트를 올릴 수 없습니다. 기본적으로 독립 심벌은 하나이며, 문자를 심벌로 대체해 심벌 두 개처럼 구성하는 예외가 문서에 있습니다. 로고를 구매한 후 벡터 파일을 외부 편집기에서 수정하는 방법은 별도입니다. [심벌 업로드][L19], [복수 심벌][L20], [커스텀 폰트][L21]

**Brand Kit는 범위가 다릅니다.** TTF·OTF·WOFF 폰트 업로드와 폰트 쌍 설정을 지원하지만 업로드 폰트가 로고 자체에 적용되지는 않습니다. [Brand Kit 폰트][L22], [로고와의 구분][L21]

**구매 후 편집:** 디자인 수정·재다운로드는 허용하되 회사명은 잠깁니다. 2024-08-27 도움말은 고객지원이 오타·리브랜딩에 대해 1회 이름 변경을 도울 수 있다고 명시합니다. “무제한 수정”을 다중 브랜드 무제한 생성으로 해석하면 안 됩니다. [가격 FAQ][L05], [회사명 예외][L23]

### 2.4 가입·한글·문서 공백

- **공식·높음:** 게스트 제작은 가능하지만 계정에 저장하려면 무료 가입이 필요합니다. 게스트 상태에서 캐시를 지우면 작업 접근을 잃을 수 있으며, 세션이 끝나면 이전 세션의 변경을 undo로 되돌릴 수 없습니다. [저장][L03], [이용 환경][L25]
- **공식·높음:** 일부 특수문자가 폰트에서 지원되지 않고, 미지원 문자를 포함하면 이름 업데이트가 안 될 수 있습니다. [특수문자][L24], [텍스트 쌓기][L14]
- **미검증:** 한글·한자·일본어의 지원 폰트 목록, 한글 IME 조합, 자모·완성형 처리, 이름 최대 길이, 한글 출력 품질은 확인하지 못했습니다. 외부 폰트 업로드 불가는 한글 전면 불가의 증거가 아닙니다.
- **공식·중간:** 다운로드를 포함한 전체 기능은 데스크톱/노트북 Chrome을 권장합니다. 모바일에 일부 기본 기능이 있다고만 안내합니다. [환경 도움말][L25]
- **권리 범위:** 전체 완성 로고의 소유와 개별 심벌의 독점 소유는 다르다고 가격 FAQ가 명시합니다. [가격·권리 FAQ][L05]

### 3.2 생성 기술·유형·편집

**역사적 공식:** 기술 글은 아이콘+타이포그래피+색 구성의 로고를 설명하며, 아이콘 가독성과 유사성을 CNN으로 점수화하고 신경망 임베딩으로 폰트·아이콘을 연결한다고 밝힙니다. 색은 미리 생성한 팔레트와 단어 벡터를 이용하고 GAN을 언급합니다. 글 하단은 앱이 이후 업데이트됐다고 명시합니다. 따라서 이것은 기술적 계보의 근거이지 현재 chat 앱이 같은 파이프라인을 그대로 사용한다는 증거는 아닙니다. [공식 기술 글][B05]

**공식·중간:** 현재 제품 설명에서 텍스트를 클릭해 수정하는 브라우저 편집, 모바일 사용, SVG·PNG·PDF 출력, 구매 후 무제한 수정을 확인했습니다. 그러나 워드마크·모노그램·아이콘형을 별도 모드로 선택하는 전체 목록, 좌표·회전·자간·글리프·레이어·커스텀 폰트·참조 이미지 업로드의 지원 여부는 문서만으로 확정하지 못했습니다. [현재 홈페이지][B01]

**중요한 해석:** “GAN을 사용했다”는 옛 글을 근거로 모든 현재 로고를 이미지 확산 생성이라고 분류하거나, 반대로 현재도 오직 고정 아이콘 조합만 가능하다고 분류하는 것은 모두 과도합니다.

공식 문서가 **Typically**라고 한 가격이며 연간 할인과 할인 코드도 언급합니다. 실제 계정의 가격·갱신 할인·세금·통화는 미검증입니다. 기본 패키지는 월/연 구독이고 로고 하나에 연결됩니다. 다른 로고로 교체하거나 새 로고를 다운로드하려면 별도 구독이 필요합니다. 취소 후에는 기존 로고 라이선스와 파일 접근을 유지한다고 안내합니다. [구매 FAQ][D05]

**무료의 세 경계:** 무료 카탈로그 로고는 고해상도와 벡터까지 제공한다고 일반 도움말이 설명합니다. 무료 로고로 웹사이트·Link in Bio·디지털 카드를 만들고 게시할 수 있지만, 다른 디자인 도구의 고품질 출력은 프리미엄 계정이 필요하다고 안내합니다. 별도로 구매 FAQ는 무료 계정에서 AI 도구로 제작한 디자인을 다운로드할 수 없다고 합니다. [무료 범위][D04], [무료 AI 제한][D05]

AI 랜딩의 “free AI-generated templates”와 구매 FAQ의 “AI 도구 제작물 유료”를 합쳐 모든 AI 생성물이 무료라고 결론내리지 않았습니다. **선정된 무료 템플릿과 사용자 AI 제작/수정 결과를 구별해야 한다는 해석**이며 실제 아이콘 AI 편집 후 무료 유지 여부는 체크아웃 확인이 필요합니다. [AI 마케팅][D01], [구매 조건][D05]

**계정·공식·높음:** 이메일·Google·Facebook으로 무료 가입합니다. 계정은 사용자 한 명용이며 좌석 추가를 지원하지 않습니다. 언어 설정 변경은 가능하지만 목록에 한국어가 포함되는지는 읽힌 본문에서 확인하지 못했습니다. 지원 통화 목록에 없는 통화는 USD로 처리한다고 안내해 원화 결제 견적을 보장할 수 없습니다. [계정·결제][D10]

**라이선스·공식·높음:** Free/Standard는 비독점입니다. Exclusive는 가능한 로고에 한해 추가 구매하면 도안을 카탈로그에서 제거하며 전체 IP 권리를 제공한다고 설명합니다. Buyout은 이후 판매를 막지만 기존 구매자의 권리를 유지합니다. 기본 로고 구독은 일회 상품이 아니지만, 라이선스 업그레이드에는 일회 결제 선택도 안내돼 있습니다. 두 구매 대상을 구분해야 합니다. [라이선스 FAQ][D09]

**미검증:** 한글 이름·혼합문자·폰트 누락, 글자 최대 길이, AI 프롬프트의 한국어 이해도, 음성 입력의 공식 지원 범위, 생성/채팅 횟수 제한, 참조 이미지 기반 신규 생성, 외부 로고 업로드의 파일 규격·벡터화·가격. 음성 관련 검색에 나오는 업종별 “Voice Logos” 카탈로그는 음성 입력 기능의 근거로 사용하지 않았습니다.

2. 게스트로 시작해 후보 열람·저장·편집·다운로드의 가입 강제 시점을 구분해 주세요.
3. Brandmark chat와 v3의 입력 단계·편집 옵션·크레딧·결제 호환성을 확인해 주세요.
4. Design.com 무료 도안에 AI 아이콘 수정을 적용했을 때 무료 다운로드가 유지되는지 확인해 주세요.
5. 결제 직전 패키지·기간·통화·최종 금액을 기록해 주세요. 이번 문서의 공개 가격과 다르면 실측 날짜를 따로 남겨 주세요.
6. 다운로드 권한이 있는 경우 PNG 투명도, SVG/EPS 벡터 구조, 한글 보존, favicon·SNS·애니메이션 파일을 확인해 주세요.
