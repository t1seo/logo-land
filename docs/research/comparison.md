# 조사 결과와 플러그인 적용

상세 근거는 [공식 기능](official-features.md), [공개 사용 기록](looka-fiverr-design-walkthrough.md), [Brandmark·Tailor 기록](brandmark-tailor-walkthrough.md), [Chrome 추가 조사](chrome-followup.md)에 있습니다. 아래 표는 그 자료를 설계 관점에서 종합한 해석입니다.

| 서비스 | 주요 제작 방식 | 직접 확인한 강점 | 플러그인 적용 |
|---|---|---|---|
| Looka | 업종·선호 로고·색·심볼 선택 뒤 후보 조합 | 취향을 글로 설명하기 어려운 사용자에게 시각적 선택 제공; 배치·글꼴·컨테이너 대안과 응용물 | 핵심 질문만 단계적으로 묻고 시안을 비교 |
| Brandmark | 현재 앱의 폼 생성·템플릿·빈 캔버스·문장→아이콘, 별도 v3 | 글꼴·아이콘·배치 교체; 로그인 후 아이콘 Generate·Refine·Variants와 Paint 패널 | 로고 유형과 스타일을 구분하고 다른 디자인 방향을 개별 생성 |
| Tailor Brands | 사업 정보·Icon/Name/Initial 유형·아이콘/서체 선택 | 유형별 온보딩; 로그인 후 이니셜 수정·무료 샘플·적용 예 | 유형에 맞는 브리프와 프롬프트 |
| Fiverr | 디자이너 로고를 업종·스타일·성격에 매칭 | 다섯 성격 축; 디자이너 변형; 글꼴·자간·곡선·도형·팔레트; Noto Sans KR 실제 렌더링 | 선택안 ID와 수정 요구를 분리하고 정확한 표기 검수 |
| Design.com | 템플릿·키워드/문장 진입·AI 채팅 수정 | 텍스트·배경·레이아웃·모양·애니메이션 패널과 자연어 편집 | 원본 참조 수정, 배경별 실제 파일 확인, 최종 적용 크기 검수 |

## 유형과 스타일

워드마크(문자 중심), 레터마크(이니셜 나열), 모노그램(글자 결합), 그림형 심볼, 추상 심볼, 심볼+문자 조합, 엠블럼, 마스코트가 플러그인의 유형 축입니다. 미니멀·기하학·유기적·빈티지·럭셔리·수작업 느낌 등은 별도 스타일 축입니다. 경쟁사의 메뉴 라벨이 모두 같은 분류 체계를 쓰는 것은 아닙니다.

가로형·세로형·아이콘 단독·단색·반전·투명 배경·아바타는 같은 아이덴티티의 파생 버전으로 처리합니다. 명함·티셔츠·간판 같은 목업은 적용 예이며 마스터 로고와 별도 파일로 구분합니다.

## 구현 범위

스킬이 사용자와 대화하고 내장 이미지 도구를 호출합니다. helper는 입력을 파싱하고 원본·프롬프트·부모 관계·선택·검수를 저장합니다. 마지막에는 실제 PNG, 브랜드 안내, manifest와 ZIP을 전달합니다. 수정 프롬프트에서 최신 요청이 초기 브리프보다 우선하도록 명시합니다.

사이트의 벡터 편집기, 고정 템플릿 라이브러리, 애니메이션 내보내기, 폰트 파일, 사람 디자이너 의뢰, 결제·구독·LLC 설립을 구현했다고 주장하지 않습니다. 상용 SaaS의 모든 화면을 복제하는 대신 사용자에게 필요한 로고 상담·시안·수정·검증·전달 과정을 구현한 것입니다.

## 자료를 읽을 때의 주의점

- Brandmark의 공개 웹 가격표와 실제 새 앱·v3의 Basic 구성/가격이 달랐습니다. 앱별 실측을 함께 남겼으며 하나의 가격으로 합치지 않았습니다.
- Design.com 공개 FAQ 금액과 계정의 프로모션 요금이 달랐습니다. 실제 화면의 결제 주기와 합계를 별도로 기록했습니다.
- 한글 입력란에 문자가 들어가는 것만으로 로고 렌더링이 성공한 것은 아닙니다. Fiverr의 글리프 누락과 글꼴 변경 성공을 모두 캡처했습니다.
- 유료 다운로드를 구매하지 않아 실제 벡터 구조·폰트 임베딩·제공 ZIP의 모든 항목은 확인 범위 밖입니다. 공식 자료로 확인한 항목은 해당 출처에 표시했습니다.
