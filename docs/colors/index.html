Session evidence JSON

01 / COLOR

Intent beside measurement.

Swatches describe the palette bound to each artifact. Reports sample a 128 × 128 grid; near matches are measured with a ΔE threshold. Opaque backgrounds count. Fully transparent pixels and CSS preview surfaces do not.

Reference palettes came from the real SUNROOM and GROVE originals. SUNROOM’s full image is dominated by ivory; the selected brown is an extracted representative, not a claim of exact original ink.

02 / LETTERING

A requested appearance.

Horizontal and stacked arrangements, exact English or Korean text, and named font references are saved as intent. Fraunces, Space Grotesk, Montserrat, Noto Serif KR and Noto Sans KR name an appearance, not a verified installed font.

No font binaries were installed or bundled. Logos are native rasters; there are no editable text layers or vector claims.

03 / PROVENANCE

Every original preserved.

All displayed PNGs are byte-for-byte copies of the native outputs. No drawing, recoloring or background removal was applied. Preview controls only change CSS. Gray squares in failed outputs are already painted into those files.

These are fictional demonstration briefs and real generation attempts. Open all case metadata. Each session links the original prompt, reports, source basename and SHA-256. No page depends on an external font, script or service.
