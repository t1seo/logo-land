# 색상과 글자

[English](README.md) · [한국어](README.ko.md) · [문서](../README.ko.md) · [Logo Land](../../README.ko.md)

일곱 프로젝트의 여덟 사례에서 색상 선택, 글자 표현, 가로·세로 배치를 보실 수 있습니다.

| 샘플 | 방향 | 제공 결과 |
|---|---|---|
| [SUNROOM](projects/sunroom/README.ko.md) | 따뜻한 팔레트 · 가로형 세리프 | 원본만 제공; 작은 부제 검수 실패 |
| [NORTHLINE](projects/northline/README.ko.md) | 남색 · 세로형 전체 이름 | PNG, ZIP, 가이드 |
| [GROVE SUPPLY](projects/grove/README.ko.md#original) | 녹색 기준색 · 가로형 산세리프 | 투명 PNG, ZIP, 가이드 |
| [GROVE, 따뜻한 색상](projects/grove/README.ko.md#warmer) | 더 따뜻한 보조색 | 불투명 체크무늬; 패키지 없음 |
| [밤결](projects/bamgyeol/README.ko.md) | 제한 팔레트 · 세로형 한글 세리프 | 미확정; 원본만 제공 |
| [TIDE & TYPE](projects/tide/README.ko.md) | 참고 이미지 색상 · 가로형 세리프 | PNG, ZIP, 가이드 |
| [FIELD NOTE](projects/fieldnote/README.ko.md) | 두 색 요청 · 세로형 산세리프 | 미확정; 원본만 제공 |
| [밤결, 흰색](projects/white-bamgyeol/README.ko.md) | 흰색 수정 · 세로형 한글 세리프 | 미확정; 승인된 투명 결과물 없음 |

요청한 폰트는 외형의 참고 기준이며, 이미지에 편집 가능한 글자나 폰트 사용권은 포함되지 않습니다.
