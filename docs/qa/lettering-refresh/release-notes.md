# Logo Land v0.7.0 — Let the letters lead

Create logos in which the lettering is the identity: playful multicolor wordmarks, kinetic lettering, geometric initials and custom Hangul. This update adds type-specific prompt construction and practical examples while retaining the existing project format and eight logo types.

- Wordmarks, lettermarks and monograms now receive distinct construction guidance. Exact brand text, letter counters, spacing and reading order are explicit.
- Follow-up edits preserve the selected parent's visible lettering instead of restoring stale text or style from the initial brief. Existing app-icon and palette behavior remains intact.
- A new mint-and-lilac Logo Land wordmark, matching badges and rewritten English/Korean READMEs replace the previous presentation.
- All ten brand examples and six app icon studies were newly generated. One board presents the complete collection, with separate original PNGs, exact prompts, native receipts and two preserved parent corrections.
- Installation and release links now use the current repository, `t1seo/logopia`. The plugin invocation remains `$logo-land`.

Results remain raster PNGs. Generated text, background and colors require inspection; strict palette exports still require measured conformance. This release does not provide editable font files, vectors, platform icon layers or an exact-color guarantee. Earlier failed color experiments remain documented and are not reclassified by this release.

See `docs/qa/lettering-refresh/verification.md` for the test and browser evidence included in the release source, and `docs/showcase/2026-09/README.md` for the original artwork.
