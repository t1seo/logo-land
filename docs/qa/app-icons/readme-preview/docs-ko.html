Logo Land 문서

English · 한국어 · Logo Land

Codex와 함께 로고를 만들고 앱 아이콘 아트워크를 비교하거나 저장한 프로젝트를 이어서 작업하실 수 있습니다.

시작하기

  • 설치: 저장소에서 바로 사용하거나 다른 프로젝트에서 플러그인을 활성화하실 수 있습니다.
  • 요청 예시: 브랜드, IP 캐릭터, 수정 요청으로 시작해 보세요.

샘플

  • 브랜드 로고: 로고 유형 8가지로 만든 개별 브랜드 10개입니다.
  • 색상과 타이포그래피: 프로젝트 7개의 사례 8개와 실제 결과입니다.
  • 앱 아이콘: IP 시안 6개와 원본·수정 방향 비교 5쌍입니다.
  • 투명 배경 로고: GROVE 예제와 배경 사용 안내입니다.
  • Logo Land 로고: 현재 로고, 다운로드와 이전 로고입니다.

사용 안내

  • 로고 방향
  • 색상과 팔레트
  • 글자와 폰트 참고
  • 앱 아이콘 아트워크
  • 수정 이력과 프로젝트 파일
  • 전달 전 검사
