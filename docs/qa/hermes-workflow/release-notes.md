# Logopia 0.8.0 — A guided workflow in Hermes

Logopia now supports a guided native Hermes workflow: describe the brand, compare distinct directions, inspect actual original PNGs with two separate model critiques, then choose and request a focused revision. The existing Codex `$logo-land` workflow remains available.

- **Native Hermes setup on macOS and Linux.** Install into an explicit named profile, retaining its provider/model choice. The installer sets that profile's native tool limits to 30 minutes; the launcher has a separate 30-minute default deadline and verifies saved outcomes.
- **Preserved originals and decisions.** Exact parent PNGs, prompts, hashes, keep/change feedback and review history stay attached to each revision. Up to two requested image edits are allowed per workflow. An explicit review-only continuation can use the remaining critique attempt; an unknown image outcome is never automatically retried.
- **Portable comparison and delivery.** Open the offline HTML page to compare originals and display-size previews, then copy feedback back to Hermes. Selection alone does not approve an export. Original PNG links remain available regardless of review status; final packages appear only when their required checks pass.
- **English and Korean entry points.** Hermes setup is visible above the existing sixteen-logo README showcase, whose original files and direct links remain intact.

The [actual OFFCUT example](https://github.com/t1seo/logopia/blob/v0.8.0/docs/hermes-demo/README.md) contains three initial PNGs and two exact-parent edits. Its **c1 → e1 → e2** history retains the first edit's failed preservation check; e2 restored the protected gap, passed both model reviews and was delivered at revision 47. The [original PNGs and delivered ZIP](https://github.com/t1seo/logopia/blob/v0.8.0/docs/hermes-demo/README.md) are included in this checkout. Download the example folder and open `index.html` locally. The [execution record](https://github.com/t1seo/logopia/blob/v0.8.0/docs/qa/hermes-workflow/native-run.md) also preserves the initial native timeout and explicit review-only recovery without new image jobs.

Reviews are model observations, not human certification or evidence of professional superiority. Output is raster PNG, with checked PNG/ZIP/brand-guide delivery when eligible; editable vectors, font files, trademark clearance and platform icon packages require separate work. Colors in the Hermes brief are advisory; the existing Codex path supports strict palette workflows.
