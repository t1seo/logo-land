# 로고 생성 플러그인 작업 초안

## 확인된 요구사항
- Looka, Brandmark, Tailor Brands, Fiverr Logo Maker, Design.com의 제작 방법과 기능 조사.
- 브라우저를 직접 조작하여 주요 단계 스크린샷 저장 및 정리.
- 대화하며 Codex 이미지 생성 기능으로 최종 로고 제작.
- 계획 수립 후 실제 구현 및 테스트까지 진행.
- Orca 워크플로 사용. 모든 사용자 설명은 친절한 존댓말.

## 기본 가정
- 음성 입력의 '딕스'는 현재 저장소의 `docs/`로 해석합니다.
- 사용자 확정: “Codex에서 직접 생성하는 플러그인으로 진행”. 조사한 제작 경험을 Codex 대화형 플러그인으로 구현합니다.
- 회원가입·결제·CAPTCHA 뒤의 기능은 공식 문서 확인과 직접 확인을 구분합니다.

## 발견 사항
- 저장소에 `.codex-plugin/plugin.json`, README, 빈 skills 디렉터리만 있습니다.
- Orca 1.4.198 런타임 연결 확인. Run: `run_fdd802989645`.
- Looka: 업종 → 선호 로고 → 색 → 브랜드명/슬로건 입력.
- Design.com: 상호 입력 → 로고 그리드 → 스타일/색 필터와 키워드 검색.
- Fiverr: 사람 확인 화면으로 직접 탐색 제한.
- 공식 기능 조사와 Metis 설계 검토를 Orca 별도 작업으로 실행 중입니다.

## 검증 방침
- 구조 및 스킬 검증, 상태/파일 처리 회귀 테스트.
- 실제 내장 이미지 생성 호출, 선택 시안 편집, 결과 파일 검사.
- 로그인/결제/벡터/투명 배경 미확인 사항을 성공으로 처리하지 않습니다.
